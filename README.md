A token launch radar: ranks 201 pre-token DeFi protocols by implied launch value, calibrated from the sealed snapshot's own 128 live-token comps (size-fitted log-log FDV/TVL curve, category factors, growth and maturity), with a concrete, mechanism-aware farm plan and a FARM / THIN / SKIP verdict for every row and an offline, sortable dashboard with a per-protocol detail view.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```
